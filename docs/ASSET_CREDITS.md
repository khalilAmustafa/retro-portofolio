# Asset credits

- CRT bezel, CSS shell, original project captures and ROOMS video: reused from the supplied Desktop portfolio. Existing project attribution in `src/data/projects.js` remains intact. No new ownership claim is made.
- Gamepad model and 1K textures: Josh Dean, Poly Haven, https://polyhaven.com/a/gamepad . CC0, https://polyhaven.com/license . Downloaded model and dependencies total 1,320,822 bytes. Served locally in `public/assets/experience/gamepad/`.
- ROOMS, Space Day and BandUp cover illustrations: generated with the built-in image generation tool for this prototype. These are illustrative portfolio artwork, not product screenshots. Prompts requested flat portrait covers in cobalt/orange (quiz arena), olive/ivory (mission passport), and coral/ivory (learning path), with the project title and Khalil Mustafa credit. The generated files were converted to WebP without modifying the originals.
- Room architecture, TV body, console, lamp, furniture, sketch and procedural surface textures: created in Three.js for this prototype.
- Fonts: retained original Google Fonts configuration (Archivo Black, IBM Plex Sans and IBM Plex Mono), with system fallbacks.
- Arc Marumo, OOS, Henry Heffernan and the approved concept image informed the design direction. Their assets, code and branding were not copied.

The existing CRT front is captured from its browser-rendered CSS and bezel for the room presentation; the settled interface uses real HTML/CSS. Source image is `crt-front.png`.

## Portfolio atlas
Coastline data: Natural Earth 1:110m land polygons, public domain. Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson . Local file public/assets/atlas/land.geojson (~138 kB). Project covers are code-built layouts using the portfolio's own project captures, with original typography and colors. No Arc Marumo image, logo or font files are used. Arc Marumo is the interaction/composition reference: https://www.arcmarumo.com/ .
